## Outcome and implementation scope

- Add repeat container, count selector and primitive body slots
- Support atomic move/delete/undo of grouped nodes
- Expose equivalent keyboard/tap controls and clear invalid-draft state

## Acceptance criteria

- [ ] Repeat child blocks are counted even when the group is collapsed
- [ ] No drag/drop or paste can create a nested repeat
- [ ] A collapsed group still communicates order, count and accessible content

## Required validation

- [ ] Test counts, empty bodies, full cap, reorder and undo
- [ ] Run 360 px, zoom and keyboard-only repeat editing journeys
