## Outcome and implementation scope

- Create local profile/settings/drafts/progress stores with Dexie abstraction
- Persist edits and selected robot with explicit error handling
- Provide in-memory play when storage fails

## Acceptance criteria

- [ ] Reload restores stable drafts and settings but not an in-flight run
- [ ] No saved indicator precedes successful write
- [ ] Storage denial does not prevent the first six puzzles from being played

## Required validation

- [ ] Test durable save and denied/quota-error fallback
- [ ] Verify incomplete drafts remain drafts and cannot execute without validation
