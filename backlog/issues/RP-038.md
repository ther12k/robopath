## Outcome and implementation scope

- Handle context loss, invalid content, unavailable rendering and asset errors
- Recover at an authoritative action boundary with draft intact
- Differentiate retryable network problems from incompatible content

## Acceptance criteria

- [ ] No blank page or hidden uncaught error is the only feedback
- [ ] Recovery never grants a not-yet-displayed success
- [ ] Retry/cancel navigation works without orphan scenes

## Required validation

- [ ] Inject context loss and corrupt/missing assets
- [ ] Test reconnect and scene recreation during paused playback
