## Outcome and implementation scope

- Implement integer-grid projection and consistent foot pivots
- Render terrain, walls, goal and pickups from data
- Fit board to its available rectangle and use deterministic object depth

## Acceptance criteria

- [ ] Logical tile positions agree with rendered markers at each facing
- [ ] Tall decoration cannot obscure critical board information
- [ ] Resize changes framing only, not simulation state

## Required validation

- [ ] Capture board at all required viewport classes
- [ ] Test robot depth on both sides of tall scenery and no-WebGL recovery entry
