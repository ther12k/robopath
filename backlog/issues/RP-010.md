## Outcome and implementation scope

- Build semantic palette, insertion slots and block action menu
- Implement pointer threshold/capture, insertion preview and canceled drops
- Provide equivalent tap-to-place and keyboard operations with announcements

## Acceptance criteria

- [ ] Every edit is possible without dragging
- [ ] Off-target drops and pointercancel never leave ghost blocks
- [ ] Focus follows edits and native page scrolling remains usable

## Required validation

- [ ] Run touch/pointer integration tests and keyboard-only flows
- [ ] Test full strip, landscape, Escape cancel and screen-reader edit announcements
