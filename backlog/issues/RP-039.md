## Outcome and implementation scope

- Implement semantic board inspection using the same logical state
- Review keyboard/tap parity, focus, contrast, zoom and modal behavior
- Run desktop/mobile screen-reader sessions and document limitations

## Acceptance criteria

- [ ] All essential puzzle interactions are possible without dragging
- [ ] Board cells, facing, objects and gate state are inspectable without vision
- [ ] No accessibility claim is based only on automated checks

## Required validation

- [ ] Run automated accessibility scans on all major screens
- [ ] Manually finish primitive, repeat and gate puzzles with keyboard/screen reader
