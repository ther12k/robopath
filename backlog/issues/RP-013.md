## Outcome and implementation scope

- Implement controller messages and renderer acknowledgments with runId and step index
- Ignore stale/out-of-order events
- Dispose all scene subscriptions, timers and owned resources on teardown

## Acceptance criteria

- [ ] No simulation or scoring happens inside scene callbacks
- [ ] Old acknowledgments cannot mutate a new run
- [ ] Repeated navigation does not add duplicate listeners/canvases

## Required validation

- [ ] Mount/destroy 100 times in a lifecycle probe
- [ ] Inject stale and duplicate acknowledgments and inspect resulting state
