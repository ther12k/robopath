## Outcome and implementation scope

- Build four free starter cards with large preview and selected check
- Persist confirmed selection through the storage adapter
- Use the selected character in welcome, board, tutorial/hint and results

## Acceptance criteria

- [ ] Changing robot preserves drafts, awards and world progress
- [ ] Selection can be changed without payment or game advantage
- [ ] Mid-run changes are deferred or require reset, never swap an active sprite unsafely

## Required validation

- [ ] Reload and verify selected robot
- [ ] Compare a fixture trace and ratings for all four robot choices
