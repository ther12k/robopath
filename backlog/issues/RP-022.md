## Outcome and implementation scope

- Compile repeat counts 2–5 with primitive-only bodies
- Charge repeat header/body static blocks and primitive runtime actions
- Preserve child source IDs and iteration metadata

## Acceptance criteria

- [ ] Nested/empty/disallowed repeats are rejected
- [ ] A repeat header costs no runtime action
- [ ] Early success truncates playback without changing full-program block cost

## Required validation

- [ ] Run w2 examples and expansion-limit negatives
- [ ] Test repeated body turns, budget boundaries and deterministic trace source mapping
