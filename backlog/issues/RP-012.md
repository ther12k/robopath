## Outcome and implementation scope

- Provide clearly labeled temporary Pip, Mochi, Bolt and Sprout assets
- Match directional poses, dimensions and ground pivots
- Map semantic asset-set IDs to local trusted files

## Acceptance criteria

- [ ] All four characters are recognizably robotic
- [ ] No robot changes rule parameters or occludes a different number of tiles
- [ ] Missing art falls back visibly without crashing

## Required validation

- [ ] Preview all poses and selected portraits side by side
- [ ] Verify asset IDs and equal logical traces for each robot ID
