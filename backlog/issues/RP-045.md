## Outcome and implementation scope

- Create developer/research-only local counters for command edits, runs and hint requests
- Provide adult-initiated anonymized export with bounded retention
- Exclude collection/transmission from the default public build

## Acceptance criteria

- [ ] No remote gameplay event endpoint or persistent tracking ID exists
- [ ] Research mode is explicit and cannot be activated by an untrusted URL
- [ ] Export contains no names, recordings or device fingerprint

## Required validation

- [ ] Inspect public bundle/network behavior for absent diagnostics
- [ ] Validate bounded local export and erase behavior

Provide changed files, exact commit/build/content versions, commands executed with results, and relevant screenshots/traces/report paths.
