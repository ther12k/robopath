## Outcome and implementation scope

- Implement version migrations and future-version rejection
- Build size-bounded export/import with preview and atomic replacement
- Implement explicit erase and stale-tab generation protection

## Acceptance criteria

- [ ] Failed import/migration preserves prior data
- [ ] Incomplete drafts are restored only as drafts; changed revisions are handled explicitly
- [ ] Another tab cannot resurrect erased progress

## Required validation

- [ ] Test malformed/oversized/prototype-key/future-version imports
- [ ] Test migration interruption, storage denial and multi-tab erase
