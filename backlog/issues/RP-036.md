## Outcome and implementation scope

- Create trusted immutable pack manifests and staging cache downloads
- Verify bytes/hashes/schema/assets before committing ready status
- Add progress, cancel, retry, quota and missing-pack states

## Acceptance criteria

- [ ] Ready means the complete verified pack exists
- [ ] Partial failure preserves a previous ready revision
- [ ] No arbitrary URL from imported data is fetched

## Required validation

- [ ] Interrupt downloads at each phase and restart
- [ ] Test quota errors, orphan staging cleanup and missing files behind a ready record
