## Outcome and implementation scope

- Implement spacing, type, palette, focus and safe-area tokens
- Create buttons, dialog, status chip, cards and loading/error primitives
- Add an isolated component showcase for review

## Acceptance criteria

- [ ] Primary targets are at least 48 CSS pixels
- [ ] Disabled, focused and error states are perceivable beyond color
- [ ] Components reflow at 360 px and 200% zoom without unreachable controls

## Required validation

- [ ] Measure target sizes and contrast in representative states
- [ ] Keyboard-test dialog entry, escape and focus return
