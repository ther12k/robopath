# Stack recommendation summary

## Short answer

Use the current **web stack** and improve its implementation quality.

## Recommended stack for this repo

- **React** — application shell and screens
- **Phaser** — puzzle board and animation
- **TypeScript** — shared type-safe domain code
- **Dexie** — local progress and settings
- **Vite** — dev/build
- **dnd-kit** — programming tray interactions
- **Framer Motion** — shell animation and delight
- **Howler** — short sound effects

## Why not Flutter / React Native / Ionic now?

Because the repo is already on the correct architecture for a mobile-first puzzle game on the web. Re-platforming would cost time while barely helping the real issue: visual polish, asset consistency, and component craft.

## What to optimize instead

- stronger custom assets,
- more deliberate component styling,
- better motion,
- a clearer robot-selection experience,
- a cleaner bridge between Phaser and React.
