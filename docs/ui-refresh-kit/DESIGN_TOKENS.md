# Design tokens and component language

## Core palette

- Ink: `#17324D`
- Pale Sky: `#EFF9FD`
- White: `#FFFFFF`
- Primary Blue: `#246FE5`
- Action Green: `#207A46`
- Sunny Yellow: `#F5BD35`
- Soft Coral: `#E77A70`
- Repeat Purple: `#7056C8`
- Water: `#8FD3FF`
- Grass: `#9BE267`
- Stone: `#B8C4D1`

## Spacing scale

Use: `4, 8, 12, 16, 24, 32`

## Radii

- Chips: `16px`
- Command blocks: `16px`
- Buttons: `18px to 24px`
- Cards and panels: `24px to 28px`

## Shadows

Prefer soft friendly shadows:
- primary cards: `0 10px 24px rgba(23, 50, 77, 0.08)`
- small controls: `0 6px 14px rgba(23, 50, 77, 0.08)`

## Typography

- Headings: bold, rounded-feeling sans
- Body: clean sans-serif, easy for kids and parents
- Avoid tiny instructional text

## Component priorities

You need these components to visually lock the app together:

- `PrimaryButton`
- `SecondaryButton`
- `IconButton`
- `RobotCard`
- `WorldCard`
- `LevelCard`
- `CommandBlock`
- `ProgramSlot`
- `ObjectiveChip`
- `ResultPanel`
- `CoachmarkDialog`

## Motion principles

- Press feedback: 80–120 ms
- Panel transitions: 160–220 ms
- Robot move: 350–450 ms
- Success celebration: short and punchy

## Feel target

The app should feel like:
- a toy,
- a reward system,
- a tiny puzzle adventure,

not like:
- a dashboard,
- a form app,
- an educational worksheet.
