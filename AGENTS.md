# Agent operating contract

This kit is a planning baseline. Follow the user’s actual repository instructions and preserve existing work. Do not infer existing implementation, final design approval or human sign-off from generated documentation.

## First actions

Read README/PRD, inspect the repository, run the local kit checks, and select the next dependency-ready task. Honor M0 before M1. The task manifest contains future IDs in dependency lists; use a topological sort rather than numeric order. M5 is optional.

## Invariants

Core rules are framework-independent and deterministic. React owns semantic controls; Phaser owns presentation; the controller owns playback/run IDs; storage owns durable transactions. Four free robots are cosmetic-only. Budgets distinguish full-AST blocks from executed primitives. No nested loops, robot abilities, live AI, backend, advertisements, accounts or production tracking in v1. Retry/reset retain drafts. Every essential drag action has a tap and keyboard equivalent.

## Evidence and change discipline

Use small changes and real tests. Update related schemas/fixtures/docs when behavior changes. Never replace the core with a canned success animation or hardcoded answers. Never use a static concept image as a finished responsive screen. Generated mockups, reference Python checks and a curriculum brief are not production evidence.

Check tasks off only when their acceptance criteria and actual evidence exist. Mark unavailable physical tests, human child studies, privacy/legal approvals and art approval as not run/blocked. Do not invent test outputs, screenshots, device support, performance numbers or legal consent.

No publishing, external issue creation, credential work, analytics collection or native-store submission without explicit authorization. `scripts/import_github_issues.py` is read-only/local unless `--apply` is passed. Do not pass `--apply` simply because the script exists.

At a checkpoint include implemented issue IDs, files, exact commit, commands/results, real UI evidence, gaps and next eligible IDs. Ask only for genuinely blocking unresolved owner decisions; continue internal prototype work using stated defaults where safe.
